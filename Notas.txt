SSH-->Es protegido por llaves y la transferencia de información sea más segura y protegida.
 Una buena práctica es tener esta llave.

Crear una llave SSH
ssh-keygen -t ed25519 -C "jesusf2312@outlook.es"

[git remote add origin git@github.com:Jesusf23/my_first_reo.git] Permite conectar mi repositorio local con el repositorio de GitHub en la nube.
[git remote -v] Permite ver el nombre y la dirección del repositorio al que está anclado, por defecto el nombre es "origin" y posterior dice la dirección remota en Github.
[git pull origin main] Esta instrucción conecta el repositorio local con el de la nube. Conecta la rama local "origin" con una nueva rama o la rama virtual de GitHub "main". En mi caso, esta rama virtual es "master".
